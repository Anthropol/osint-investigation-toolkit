# osint-investigation-toolkit
Modular software suite for conducting information research(Модульний програмний комплекс для проведення інформаційних розслідувань)— навчальний проєкт на етапі розроблення. Комплекс дасть змогу OSINT-аналітику-початківцю знаходити публічні згадки нікнеймів, перевіряти домени й аналізувати метадані файлів у межах одного дослідження зі збереженням джерел та результатів, замість окремого запуску утиліт і ручного перенесення знахідок у документ. Аналоги: OSINT Framework, Sherlock, SpiderFoot
